# jotun

## Bruksanvisning:
Kjør Jotun_cycle.py i terminalen ved bruk av python:
```python3 Jotun_cycle.py [-t (txt_fil)] [-j (json_fil)] [-cfg (config_fil)] [-cst (constants_fil)]```

Hvis du kjører uten noen av flaggene vil du få opp en tabell i konsollen som før
Med -t må du oppgi en filplassering direkte etter flagget, da vil du ikke få noe opp i konsollen, men tabellen vil lagres i filen du valgte
Med -j vil data fra kalkulatoren bli lagret til en json fil du velger 
Uten -cfg eller -cst flaggene, kjører koden med config.cfg og constants.cfg som konfigurasjonsfiler
